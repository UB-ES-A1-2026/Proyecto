InicioIniciar sesiónCrear cuenta
  1. Las mismas reglas que el backend: usuario de 3 a 30 caracteres, correo válido (≤ 255) y contraseña de 8 caracteres a 72 bytes. Las ayudas se ven siempre.
  2. «Mostrar» / «Ocultar» cambia la contraseña entre visible y oculta (criterio 4).
  3. Al pulsar se valida todo a la vez. Mientras se envía, el botón dice «Creando cuenta…» y está desactivado.
  4. Lleva a /login. Allí, «Regístrate» trae de vuelta a esta pantalla.

Algún dato no es válido, o el correo o el nombre de usuario ya están registrados

Crear cuenta 2

¿Ya tienes cuenta? Inicia sesión

  1. El error sale debajo de su campo, con el texto exacto del criterio 3. Es el mismo si el dato es inválido y si ya existe: el correo o el nombre de usuario repetidos también lo muestran (el backend responde 409), solo en ese campo. El foco va al primer campo con error.
  2. No se crea la cuenta y se queda en /registro. El error desaparece en cuanto se edita el campo. Si el fallo no es de un campo, el aviso sale encima del formulario: «No se puede conectar con el servidor. Inténtalo más tarde.» o «Ha ocurrido un error inesperado.».

Todos los datos son válidos → se crea la cuenta y se inicia la sesión
