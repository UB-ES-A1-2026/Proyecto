US-01.4 Perfil público de usuario

Como usuario, quiero un perfil público con foto, bio, valoración media y mis artículos para que otros confíen en mí.

Issue #48 · Tarea de frontend #301 · Wireframe de baja fidelidad · Actualizado con asistencia de IA (Claude) tras la maqueta web de la tarea, pendiente de revisar por el equipo

Decisión de diseño: Rentit solo tiene un perfil, el público (/usuarios/:id). «Mi perfil» no es otra página: lleva al perfil público de la propia persona, donde además puede editarlo, publicar un objeto y cerrar sesión. Por eso no hay dos pantallas distintas para «público» y «privado».

Maqueta de Figma · Marco «Ficha»: «Veure perfil» está en la caja del propietario; la web enlaza el nombre de quien publica.

  1. Ventana sobre el perfil. «×», «Cancelar», la tecla Esc o un clic fuera la cierran sin guardar. Si no se ha cambiado nada, «Guardar» solo la cierra.
  2. «Subir una foto» (si aún no tiene) o «Cambiar foto» abren el selector de archivos; se ve una vista previa. «Quitar foto» vuelve a la inicial del nombre. Solo JPG, PNG o WebP de hasta 5 MB: con otro archivo sale el error junto al campo.
  3. Límite de 500 caracteres de usuario.bio (docs/modelo-datos.md). Vacía, se borra la bio. Si la API rechaza el texto, sale el error junto al campo: «El campo "bio" no es correcto, revísalo.»
  4. Guarda la bio y después la foto, solo de la cuenta de la sesión (la API rechaza editar un perfil ajeno). Mientras guarda dice «Guardando…». Si la sesión ha caducado, lleva a /login.
