  1. Nombre obligatorio, de 100 caracteres como máximo. Descripción obligatoria, de 2000 caracteres como máximo.
  2. Categoría obligatoria; las opciones se cargan desde GET /api/categorias: Herramientas y bricolaje, Electrónica, Deporte, Camping y viajes, Hogar y jardín, Fiestas y eventos, Infantil y Otros.
  3. El precio debe ser mayor que 0; acepta coma o punto y hasta 2 decimales. La fianza debe ser 0 o más; vacía equivale a 0. El barrio es obligatorio y admite hasta 100 caracteres.
  4. Las fotos son opcionales: hasta 5, JPG, PNG o WebP, con un máximo de 5 MB cada una. Se redimensionan en el navegador antes de subirlas (ADR 0002).
  5. Mientras se publica, el botón muestra «Publicando…». Los datos se envían a POST /api/objetos (#14); las fotos se suben después (#106).
  6. Si el objeto se publica pero falla alguna foto, se muestra «El anuncio se ha publicado, pero alguna foto no se ha podido subir.» y el enlace «Ver el anuncio».
  7. Sin sesión, al acceder a /objetos/nuevo se redirige a /login.
